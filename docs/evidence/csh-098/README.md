## Scope and independent oracle

Issue 8 [touch](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/touch.html)
OPTIONS defines period/comma fractions, T/space separators, local interpretation
without Z, UTC interpretation with Z, and timestamp field selection. Its
ENVIRONMENT VARIABLES section specifies TZ. DESCRIPTION, STDOUT, STDERR and
EXIT STATUS supply the unchanged-file, channel and result contracts.
`normative-sources.json` records the retrieved page hash (direct HTTPS retrieval
after the web reader returned 403).

`tests/host_filesystem_datetime.py` supplies 64 cases, each run by direct exec
and cshell string/file/stdin dispatch: 256 assertions per platform. Sixteen
spellings cover period/comma fractions (including one nanosecond and the last
nanosecond of a second), T/space separators, absent-zone UTC/fixed offsets,
explicit Z overriding nonzero TZ, and compact -t fixed-zone inputs. The authored
UTC results cross year and leap-day boundaries. Each spelling uses default,
access-only, modification-only and explicit-both selection.

UTC calendar fields and integer fractional values are authored separately from
input strings. Expected timestamps use integer Gregorian subtraction and never
provider output, a date-string parser, floating-point timestamps, mktime, the
current clock or the host timezone database. Fixed POSIX TZ strings specify no
DST. An independent unit-test table of epoch constants catches offset-sign,
rollover and fraction-scaling errors.

Before provider execution, Python verifies content and inode identity, sets the
exact expected timestamps on the target inode, reads both fields back, then
restores independently distinct fractional baselines and reads them back. A
rounded or failed setup fails before provider execution. After execution,
identity/mode/link-count and exact selected/unselected fields must match; metadata
is captured before content reads can change atime. Content, empty stdout/stderr
and zero status are required. Records retain the authored expectations, exact
arguments and TZ, probes, provider identity, output/status, effects and cleanup.

Four harness regressions exercise independent epoch expectations; altered fields,
content, inode/mode, channels and status; failed/rounded setup; and failed exec
or timeout in all four modes. Timeout tests require the owned child to have
exited and the private fixture to be removed.

These are ordinary private files with representable timestamps. No privileged
provisioning, libc fault injection, kernel fault or filesystem exhaustion is
involved. DST, external timezone databases, arbitrary precision/ranges,
creation/current-clock behavior, namespace races and permission/ACL errors remain
unqualified. No provider implementation or selected allowance changes.

## Validation and reproduction

```sh
# Native PATH must provide gtest, g[, gfind and gdd.
make -j4 cshell host-profile
python3 docs/evidence/csh-098/validate.py native

docker build -f docs/evidence/csh-098/Dockerfile.linux -t cshell-test:csh-098 .
docker create --init --name cshell-csh098-validation cshell-test:csh-098 \
  python3 docs/evidence/csh-098/validate.py linux
docker start -a cshell-csh098-validation
docker cp cshell-csh098-validation:/work/build/csh098-validation ./build/csh098-linux-results
docker rm cshell-csh098-validation

# Retain the native/Linux reports in this directory before verification.
python3 docs/evidence/csh-098/verify.py
```

`validate.py` runs all ticket-required targets and the new datetime target,
then separate stock full/provider audits; expected command statuses are 0, 2
and 1. `verify.py` requires every prior selected case, exactly 256 new passing
assertions, exact timestamps and armed inode probes, channels, cleanup, provider
manifest agreement and one final build/test source digest across platforms.
Stock failure IDs and modes are compared exactly with CSH-097.

Native qualification uses an unprivileged macOS identity. The gfind binary was
copied from CSH-097's ignored build; pinned local providers were rebuilt in this
worktree. Linux uses the recorded CSH-097 Debian image with the test/tool overlay,
Docker init, UID 10001 and no host mounts. Provider manifests and configure/build
logs are retained. No sanitizer or hosted-CI qualification is claimed.
